# Datheon Python for Data Engineering & Automation Internship

## Task 2: Data Cleaning and Schema Transformation

### Project Overview
This project uses Python and Pandas to clean tabular data and transform it into a consistent format.

### Technologies Used
- Python
- Pandas
- Google Colab
- CSV

### Tasks Performed
1. Read data from an uploaded CSV file.
2. Standardize column names.
3. Clean text values and whitespace.
4. Remove duplicate records.
5. Handle missing numeric and text values.
6. Validate the cleaned dataset.
7. Export the processed data to a new CSV file.

### Project Files
- `Task_2_Data_Cleaning.ipynb` — Python notebook containing the implementation.
- `cleaned_customers.csv` — Cleaned output dataset.

### How to Run
1. Open the notebook in Google Colab.
2. Run the code cell.
3. Upload the input CSV file when prompted.
4. Review the cleaned data and download the output CSV.

### Expected Output
A cleaned CSV file with standardized column names, consistent text formatting, duplicate rows removed, and missing values handled.
